# Eco-Conecta — Resíduos Volumosos

Versão base em HTML + CSS inspirada no wireframe enviado.

## Arquivos
- `index.html` — Landing Page
- `cadastro.html` — Login + Cadastro
- `style.css` — estilos compartilhados

## Escopo adaptado
O conteúdo foi alterado de baterias de lítio para resíduos volumosos:
- Entulhos
- Móveis inutilizados
- Podas e galhos
- Madeira
- Colchões
- Outros resíduos volumosos

## Observação
Os formulários são apenas front-end neste momento. O envio, autenticação,
persistência e integração com o restante do projeto podem ser ligados depois.
